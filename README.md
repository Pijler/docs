<h2><p align="center">Pijler Docs</p></h2>

### 🚀 Introduction

Central store for **Pijler** brand files. This repository only holds logos and related artwork so other Pijler repositories can reuse them from a single source.

There is no application or documentation site here — just the files.

### 📦 What's included

| Folder                | Format | Contents                               |
| --------------------- | ------ | -------------------------------------- |
| [`assets/`](./assets) | SVG    | Vector logos                           |
| [`images/`](./images) | PNG    | Raster exports with the same filenames |

### 🔗 Usage

Reference files from other repositories via raw GitHub URLs:

```
https://raw.githubusercontent.com/Pijler/docs/main/assets/pijler-icon-dark.svg
https://raw.githubusercontent.com/Pijler/docs/main/images/pijler-icon-dark.png
```

Example:

```html
<img
  alt="Pijler"
  height="100"
  src="https://raw.githubusercontent.com/Pijler/docs/main/assets/pijler-icon-dark.svg"
/>
```
